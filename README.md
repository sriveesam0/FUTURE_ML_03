# Resume Screening System (Machine Learning Project)

## 📌 Project Overview
This project is an NLP-based Resume Screening System that helps recruiters automatically shortlist candidates based on job requirements.

## 🎯 Objective
- Extract skills from resumes
- Match resumes with job descriptions
- Rank candidates based on relevance
- Identify missing skills

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP (Text Processing)

## ⚙️ How It Works
1. Resume text is cleaned and preprocessed
2. Skills are extracted using keyword matching
3. Job description is processed
4. Cosine similarity is used to compare resumes with job description
5. Candidates are ranked based on score
6. Missing skills are identified

## 📊 Output Example
- Candidate Score
- Extracted Skills
- Missing Skills
- Ranking

## 🚀 Conclusion
This system simulates real-world resume screening tools used in HR-tech platforms to reduce manual effort and improve hiring efficiency.
